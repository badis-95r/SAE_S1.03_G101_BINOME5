Administration Linux

Cette section détaille la configuration système effectuée après l'installation, notamment la gestion des utilisateurs et la personnalisation de l'environnement.

1. Gestion des utilisateurs et des groupes

Nous avons configuré l'environnement multi-utilisateur pour répondre aux besoins collaboratifs du projet.

Objectif Commande Justification technique
Créer le groupe sudo addgroup binome5 Centraliser les permissions de lecture/écriture pour le binôme.
Créer les comptes sudo adduser binome5_x Générer les répertoires personnels /home et les environnements de travail.
Lier au groupe sudo usermod -aG binome5 binome5_x Permettre le partage de fichiers entre les membres du binôme.
Note : Nous avons vérifié la configuration avec la commande grep "binome5" /etc/group.

2. Personnalisation de l'invite de commande (Prompt)

Afin d'identifier rapidement l'utilisateur actif et d'améliorer l'ergonomie, nous avons personnalisé l'invite de commande via la variable PS1 dans le fichier .bashrc.

export PS1="[\u@\h \W]\$ "

Explication :

  • \u : Nom de l'utilisateur courant.
  • \h : Nom de la machine (hostname).
  • \W : Dossier courant (basename).

Cette configuration évite les erreurs de manipulation en affichant en permanence le contexte de travail.

3. Configuration SSH

Pour administrer le serveur à distance et déployer les fichiers, nous avons installé et activé le service SSH.

sudo apt update sudo apt install openssh-server -y sudo systemctl enable --now ssh
