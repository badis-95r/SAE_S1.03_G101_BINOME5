Installation d'un poste pour le développement

SAE S1.03 - IUT de Paris - Rives de Seine

Introduction

Ce dossier présente le travail réalisé dans le cadre de la SAÉ S1.03 intitulée « Installation d'un poste pour le développement » au sein du département Informatique de l'IUT de Paris - Rives de Seine. Cette situation d'apprentissage et d'évaluation, qui s'est déroulée de novembre 2025 à janvier 2026, a pour objectif principal de nous initier aux techniques de virtualisation et à l'administration de services réseaux.

Le but de ce projet est double : d'une part, apprendre à préparer un poste de travail virtuel pour des besoins de développement, et d'autre part, déployer un serveur web fonctionnel pour diffuser notre production.

Organisation du rapport

Afin de retracer fidèlement notre démarche, ce rapport est structuré selon les axes suivants :

  1. Étude théorique (Virtualisation)
  2. Mise en œuvre de la Machine Virtuelle
  3. Installation du système (Debian/Ubuntu)
  4. Administration Linux
  5. Configuration du serveur Web
  6. Conclusion
