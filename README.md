# SAE S1.03 - Installation d'un poste pour le développement

Ce dépôt héberge le site web faisant office de rapport pour la **SAÉ S1.03** (Situation d'Apprentissage et d'Évaluation) intitulée « Installation d'un poste pour le développement ». Ce projet a été réalisé au sein du département Informatique de l'IUT de Paris - Rives de Seine (2025-2026).

## 👥 Auteurs

*   **Keziah GEBAUER**
*   **Badis RAHLI**

## 📝 Description du Projet

L'objectif de cette SAÉ est double :
1.  Apprendre à préparer un poste de travail virtuel adapté aux besoins de développement.
2.  Déployer un serveur web fonctionnel pour diffuser ce rapport.

Ce site documente l'intégralité de la démarche technique suivie, de la théorie à la pratique.

## 📂 Contenu du Rapport

Le site est structuré en plusieurs parties correspondant aux étapes clés du projet :

*   **Théorie :** Concepts fondamentaux de la virtualisation.
*   **Machine Virtuelle :** Configuration et mise en œuvre de la VM.
*   **Installation OS :** Installation du système d'exploitation Linux (Debian/Ubuntu).
*   **Administration :** Administration système, gestion des utilisateurs et des droits.
*   **Serveur Web :** Installation et configuration du serveur Apache2, tests PHP, et déploiement automatisé.

## 💻 Structure Technique

Le rapport est présenté sous la forme d'un site web statique, développé avec :
*   **HTML5 / CSS3**
*   **Bootstrap 5** (pour la mise en page et la responsivité)

Les fichiers sources du site se trouvent dans le répertoire `Systeme/`.
